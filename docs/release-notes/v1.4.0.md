## 한눈에 보기

- **사진 축소** — 폴더 안 사진을 긴 변 기준 픽셀로 줄여 JPG로 새 폴더에 저장합니다.
- **나란히 비교** — 같은 장면 컷을 2~4장 나란히 놓고 같은 자리·같은 배율로 비교합니다.
- **라이트룸 별점** — 베스트컷은 별점, C컷은 거부 표시를 RAW 옆 .xmp에 씁니다.
- **방금 이동 되돌리기**, **직접 고른 컷 기억**, 그리고 **미리보기가 훨씬 빨라졌습니다.**

## 새 기능

### 사진 축소 (사진 파일 정리 > 사진 축소)
- 긴 변 픽셀(예: 2048px)과 JPG 화질을 정하면, 원본은 그대로 두고 고른 폴더에 같은 이름으로 저장합니다.
- 미리보기로 사진마다 "원래 크기 → 새 크기"를 먼저 보여 주고, 긴 변 값을 바꾸면 표가 바로 바뀝니다.
- 이미 작은 사진은 키우지 않고, RAW는 건너뜁니다. 촬영 정보(EXIF)·회전 정보·파일 수정 시각은 그대로 남습니다.
- 같은 이름이 있으면 덮어쓰지 않고 번호를 붙입니다. "하위 폴더까지 포함"하면 같은 폴더 구조로 저장합니다.

### 나란히 비교 (베스트컷·C컷 선별)
- 사진을 고르고 **"나란히 비교"** 또는 **C** 키 → 같은 장면 컷이 2~4장 나란히 뜹니다.
- 확대·이동이 모든 칸에 함께 적용돼, 한 칸에서 눈을 100%로 확대하면 다른 칸도 같은 자리를 보여줍니다.
- 휠 확대 · 끌어서 이동 · 더블클릭(그 자리 100% ↔ 맞춤) · Space/P/X로 바로 넣기/빼기.

### 라이트룸 별점 (베스트컷·C컷 선별 > 출력 > 라이트룸)
- 베스트컷은 고른 별점(1~5★), C컷은 거부 표시를 RAW 옆 같은 이름의 .xmp에 씁니다. 사진 파일은 건드리지 않습니다.
- 이미 .xmp가 있으면(보정 기록 등) 다른 내용은 그대로 두고 별점·거부 칸만 바꾸며, 바꾸기 전 파일은 백업합니다.
- 라이트룸은 RAW 옆 .xmp만 읽어서 JPG만 있는 사진은 건너뜁니다. 이미 가져온 사진은 **메타데이터 → 파일에서 메타데이터 읽기**를 해야 반영됩니다. 거부 표시는 Lightroom Classic 13.2 이상에서 읽힙니다.

## 개선

- **방금 이동 되돌리기**: C컷 이동이나 베스트컷 이동, 라이트룸 별점 쓰기 직후 **"↶ … 되돌리기"** 버튼으로 마지막 작업 하나를 되돌립니다. 원래 자리에 같은 이름의 파일이 새로 생겼으면 덮어쓰지 않습니다.
- **직접 고른 컷 기억**: 선택에 넣기/빼기한 것이 앱을 껐다 켜도 남습니다("지난번에 직접 고른 n장을 불러왔습니다").
- **속도**: 사진 여러 장을 동시에 채점하고 불필요한 복사를 없애, 2400만 화소 사진 미리보기가 약 2.6배 빨라졌습니다(48장 57초 → 22초, 4코어 기준). 수천 장에서도 넣기/빼기가 즉시 반영됩니다.

## 업데이트 안내

- **v1.3.0을 쓰고 있다면** 앱을 켤 때 이 버전 알림이 뜹니다. **업데이트**를 누르면 받아서 바꾸고 다시 시작합니다(설정·점수는 그대로). 메뉴 **도움말 > 업데이트 확인…**으로 직접 확인할 수도 있습니다.
- **v1.2.0 이하**는 자동 업데이트 기능이 없어 직접 받아 바꿔야 합니다.
- macOS: 앱이 **응용 프로그램 폴더**에 있어야 자동으로 바꿀 수 있습니다. 처음 한 번은 **우클릭 → 열기**로 실행합니다.
- Windows: zip을 **먼저 푼 뒤** `PixThrough.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
