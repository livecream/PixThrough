## 한눈에 보기

- **고객 셀렉** — 고객이 브라우저에서 사진을 고르는 페이지(zip)를 만들고, 고른 결과대로 원본을 따로 모읍니다.
- **바디별 시계 맞추기**, **장면 직접 나누기·합치기**
- **쓰기 편해졌습니다** — 다음 단계 버튼, 남은 시간·끝 알림, 최근 폴더, 단축키 모음, 표로 먼저 보여주는 시간순 정렬·폴더 정리, 더 친절한 오류 안내.

## 새 기능

### 고객 셀렉 (사진 파일 정리 > 고객 셀렉)
- **① 페이지 만들기**: 폴더 안 사진을 줄여서 페이지 하나(index.html)와 zip으로 만듭니다. 인터넷 서버가 필요 없고, zip은 구글 드라이브·메일 등으로 보내면 됩니다.
  - 고객은 압축을 풀고 index.html을 열어 사진을 눌러 고르고, 크게 보며 사진마다 메모를 남길 수 있습니다. 고를 장 수를 정해 두면 "5 / 20장"처럼 보입니다.
  - 다 고르면 **선택 결과 저장**(pixthrough-selection.json 파일)이나 **목록 복사**(메신저에 붙여넣기)로 돌려보냅니다.
  - 워터마크 글자는 넣을 때만 들어가고, 사진의 촬영 정보(GPS 위치 포함)는 빼고 만듭니다.
- **② 고객이 고른 사진 가져오기**: 결과 파일을 열거나 목록을 붙여넣으면 원본과 맞춘 결과를 표로 보여 주고, **복사**를 누르면 원본(+같은 이름 RAW)을 고른 폴더로 복사합니다. 메모는 CSV로 남습니다.
- 휴대폰에서 보게 하려면 페이지 폴더를 웹에 올려야 합니다(zip은 PC용).

### 바디별 시계 맞추기 (시간순 정렬·베스트컷 화면의 "바디 시계 맞추기…")
- 카메라(바디)마다 시계가 어긋난 만큼 시차를 넣으면, 시간순 정렬과 베스트컷 장면 묶기가 맞춘 시각으로 계산됩니다.
- 시차를 직접 넣거나, **같은 순간을 찍은 두 사진**을 골라 자동으로 계산할 수 있습니다. 원본 촬영 시각은 바꾸지 않습니다.

### 장면 직접 나누기·합치기 (베스트컷·C컷 선별)
- 자동으로 묶인 장면을 **여기서 나누기(S)**, **앞 장면과 합치기(M)**로 고칩니다(장면 ▾ 메뉴·오른쪽 클릭으로도).
- 고친 장면은 간격·시차를 바꾸거나 앱을 다시 켜도 남고, 언제든 되돌릴 수 있습니다.

## 사용성 개선

- **시간순 정렬을 표로**: 바뀔 이름(굵게)·촬영 시각·RAW 짝·바디 시차를 표로 보여 주고, 바디(폴더)마다 줄 색이 달라 섞이는 모습이 보입니다. 이름으로 찾기, 고른 사진 미리보기, 미리보기 취소.
- **폴더 정리는 표로 확인 후 실행**: RAW·영상·날짜별 정리, 빈 폴더·중복 삭제 버튼은 대상을 표로 먼저 보여 주고, 아래 실행 버튼을 눌러야 실행합니다. 큰 폴더에서도 화면이 멈추지 않고 진행률·취소가 있습니다.
- **다음 단계 버튼**: 작업이 끝나면 "→ 베스트컷·C컷 선별", "→ 고객 셀렉 페이지 만들기"처럼 다음 화면으로 결과 폴더를 넣은 채 넘어갑니다.
- **남은 시간·끝 알림**: 진행률 옆에 "약 2분 남음"이 보이고, 오래 걸린 작업이 끝나면 다른 앱을 보고 있어도 Dock 아이콘(맥)·작업 표시줄(윈도우)로 알려 줍니다.
- **최근 폴더**: 메뉴 **파일 › 최근 폴더**에서 고르면 지금 화면에 넣고, 폴더 고르기 창은 마지막에 쓴 폴더에서 열립니다.
- **단축키 모음·처음 사용 안내**: **?** 키(또는 F1, 도움말 › 단축키)로 화면별 단축키를 보고, 처음 켤 때 사용 순서 안내가 한 번 나옵니다(도움말 › 처음 사용 안내로 다시).
- **오른쪽 클릭**: Finder(탐색기)에서 보기 · 기본 앱으로 열기 · RAW 열기.
- **갤러리 썸네일 크기**: 슬라이더나 Ctrl(⌘)+휠, Ctrl(⌘) +/−로 100~240px.
- **오류 안내**: 공간 부족·권한·다른 앱이 사용 중 같은 흔한 문제를 우리말로 설명하고, 출력 폴더가 원본과 겹치면 실행하기 전에 빨간 경고를 띄웁니다.
- **앱 기록**: 작업 내역과 오류를 이 컴퓨터의 기록 파일에 남깁니다(도움말 › 로그 폴더 열기). 문제가 생기면 이 파일을 보내 주세요.

## 고친 점

- 폴더 정리의 RAW·영상·날짜별 이동이 옮길 자리에 같은 이름의 파일이 이미 있으면 덮어쓰던 문제를 고쳤습니다. 이제 건너뛰고 표에 미리 알려 줍니다.

## 업데이트 안내

- **v1.3.0 이상을 쓰고 있다면** 앱을 켤 때 이 버전 알림이 뜹니다. **업데이트**를 누르면 받아서 바꾸고 다시 시작합니다(설정·점수는 그대로). 메뉴 **도움말 > 업데이트 확인…**으로 직접 확인할 수도 있습니다.
- **v1.2.0 이하**는 자동 업데이트 기능이 없어 직접 받아 바꿔야 합니다.
- macOS: 앱이 **응용 프로그램 폴더**에 있어야 자동으로 바꿀 수 있습니다. 처음 한 번은 **우클릭 → 열기**로 실행합니다.
- Windows: zip을 **먼저 푼 뒤** `PixThrough.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
