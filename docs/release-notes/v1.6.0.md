## 한눈에 보기

- **고객과 주고받기가 쉬워졌습니다** — 고객이 고른 사진을 베스트컷 화면에 표시하고 라이트룸 색 라벨로 쓰기, 카톡·메일로 보내는 휴대폰용 한 파일, 고른 사진만으로 2차 페이지.
- **더 빨리 고르기** — 전체 화면 컬링(P 남김·X 뺌), 내 선택에 맞춘 가중치 추천, 미소 점수.
- **정리·공유 도구** — 거의 같은 사진 찾기, 컨택트 시트 PDF, 영상 미리보기, 작업 기록, 설정 내보내기·가져오기.

## 새 기능

### 전체 화면 컬링 (베스트컷·C컷 선별)
- 표·갤러리에서 **F**(또는 ⛶ 버튼, 오른쪽 클릭)를 누르면 사진을 화면 가득 한 장씩 봅니다.
- **P** 남김 · **X** 뺌을 누르면 바로 다음 사진으로 넘어갑니다("P/X 누르면 다음 사진으로"를 끄면 그 자리에). **Space** 바꾸기, **←/→** 사진, **↑/↓** 장면, **Z** 100%↔맞춤, **C** 나란히 비교.
- 아래 줄에 지금 장면의 컷이 보이고(남김 초록·C컷 빨강), 다음 사진을 미리 읽어 두어 넘기는 게 빠릅니다.

### 가중치 맞추기 (베스트컷 화면 "가중치…")
- 지금 결과(자동 선택 + 직접 넣기·빼기)로 **자동 선택이 내 선택과 얼마나 맞는지** 보여 주고, 더 잘 맞는 가중치를 추천합니다.
- 추천을 누르거나 숫자를 바꾸면 일치율이 바로 바뀌고, **적용**을 눌러야 이 컴퓨터의 설정에 저장됩니다. 언제든 기본값으로 되돌릴 수 있습니다.

### 미소 점수
- 눈뜸과 함께 **미소(0~1)**도 잽니다. 표·크게 보기·나란히 비교에서 보이고, 가중치는 0으로 시작해 기존 결과는 그대로입니다 — 쓰고 싶으면 "가중치…"의 미소 칸으로 정하세요.
- 처음 미리보기할 때 저장된 점수를 한 번 다시 계산합니다.

### 고객 셀렉
- **고객 선택 표시**: 고객 결과를 가져오면 베스트컷 화면에 파란 "고객" 표시가 붙고, "고객이 고른 것만"으로 걸러 볼 수 있습니다(베스트컷 선택은 그대로). 고객 결과 파일을 베스트컷 화면에 **끌어다 놓거나** 메뉴 **파일 › 고객 선택 결과 가져오기…**로도 됩니다.
- **라이트룸 색 라벨**: 고객이 고른 사진의 RAW 옆 .xmp에 색 라벨(기본 Green)을 씁니다. 별점·보정은 그대로이고, 고치기 전 파일은 백업하며 되돌릴 수 있습니다.
- **휴대폰용 한 파일**: 사진을 HTML 안에 넣은 파일 하나를 함께 만들어 카톡·메일로 보내면 휴대폰에서 바로 열 수 있습니다(만들기 전에 예상 크기 표시). 고객은 **보내기**로 고른 목록을 바로 돌려보낼 수 있습니다.
- **2차 페이지**: 가져온 뒤 "2차 페이지…"로 고객이 고른 사진만으로 다음 차수 페이지를 만듭니다.

### 거의 같은 사진 찾기 (폴더 정리 › 살펴보기)
- 크기만 다르거나 다시 저장한 사진처럼 **거의 같은 사진**을 하위 폴더까지 찾아 묶어 보여 줍니다(차이 기준 0~20, 시작값 5). 보여 주기만 하고 옮기거나 지우지 않습니다.

### 컨택트 시트 PDF (베스트컷 화면 출력 › 공유)
- 남기는 컷을 장면 순서대로 A4 PDF에 모읍니다(한 쪽에 24장, 칸마다 장면 번호·파일 이름). 팀·고객에게 보여 주거나 출력할 때 쓰세요.

### 영상 미리보기
- 시간순 정렬·폴더 정리 표에서 영상을 고르면 옆 칸에 영상의 한 장면과 길이·해상도가 보입니다.

### 작업 기록 (파일 › 작업 기록…)
- 앱에서 한 복사·이동·되돌리기·정렬·정리·축소·라이트룸·고객 셀렉 작업을 최근 것부터 표로 보고, 폴더나 자세한 기록 파일을 바로 엽니다. 이 버전부터 기록됩니다.

### 설정 내보내기·가져오기 (파일 › 설정 내보내기… / 설정 가져오기…)
- 앱 설정과 직접 고른 컷·직접 고친 장면·고객 선택 기록을 파일 하나로 저장하고, 새 컴퓨터나 다시 설치한 앱에서 가져옵니다. 저장된 점수는 넣지 않아 처음 미리보기할 때 다시 계산합니다.
- 가져오기 전 지금 상태는 자동으로 백업됩니다. 직접 고른 기록은 같은 경로에 같은 사진이 있을 때 쓰입니다.

## 업데이트 안내

- **v1.3.0 이상을 쓰고 있다면** 앱을 켤 때 이 버전 알림이 뜹니다. **업데이트**를 누르면 받아서 바꾸고 다시 시작합니다(설정·직접 고른 기록은 그대로). 메뉴 **도움말 > 업데이트 확인…**으로 직접 확인할 수도 있습니다.
- **v1.2.0 이하**는 자동 업데이트 기능이 없어 직접 받아 바꿔야 합니다.
- macOS: 앱이 **응용 프로그램 폴더**에 있어야 자동으로 바꿀 수 있습니다. 처음 한 번은 **우클릭 → 열기**로 실행합니다.
- Windows: zip을 **먼저 푼 뒤** `PixThrough.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
