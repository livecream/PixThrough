## 한눈에 보기

- **카드에서 바로 시작** — 메모리카드의 사진을 촬영 날짜별 폴더로 복사하고(백업 드라이브에도), 원본과 같은지 하나하나 확인합니다. "한 번에 처리"로 가져오기 → 시간순 정렬 → 베스트컷 미리보기를 이어서 진행할 수 있습니다.
- **촬영 건 단위로 이어 하기** — 촬영 하나를 이름과 폴더로 기억해 다시 열면 그대로 이어서 작업하고, 여러 촬영 건을 미리 채점해 둘 수 있습니다.
- **고르기가 더 편해졌습니다** — 컬링 별점(1~5), 장면·파일 찾아가기, 사진 끌어내기, 단축키, 앱을 켜면 지난 결과 바로 보기.
- **더 안전하게** — 복사·이동 전 남은 공간 확인, 작업 기록에서 지난 이동·이름 바꾸기 되돌리기.

## 새 기능

### 카드 가져오기 (사진 파일 정리 › 카드 가져오기)
- 카드의 사진·RAW·영상을 `가져올 곳/2026-11-03/`처럼 촬영 날짜별 폴더로 복사합니다. **백업도**를 켜면 다른 드라이브에도 같은 구조로 복사합니다.
- 복사본은 원본과 같은지 하나하나 확인하고(해시), 다 맞으면 **"카드를 지워도 안전"**, 하나라도 실패하면 **"카드를 지우지 마세요"**를 보여 줍니다. 카드의 파일은 지우지 않습니다.
- 이미 가져온 사진은 건너뛰고, 바디 두 대처럼 이름만 같은 다른 사진은 `IMG_0001_101CANON`처럼 이름을 붙여 따로 둡니다(JPG·RAW 짝은 같은 이름).
- **카드 찾기** 버튼은 꽂힌 메모리카드(DCIM 폴더가 있는 드라이브)를 찾아 줍니다.

### 한 번에 처리 (카드 가져오기 화면 "한 번에 처리…")
- 카드 가져오기 → 시간순 정렬 → 베스트컷 미리보기를 이어서 진행합니다. 단계마다 표를 보여 주고, 파일을 바꾸는 가져오기·이름 바꾸기는 확인을 눌러야 실행합니다. 위에 진행 줄과 "그만하기"가 보입니다.

### 촬영 건 (파일 › 촬영 건…, Ctrl/⌘+Shift+O)
- 촬영 하나를 이름과 폴더로 기억합니다. 다시 열면 모든 화면에 그 폴더를 넣고 다음에 할 화면으로 가며, 어디까지 했는지(✓ 가져오기 · 정렬 · 베스트컷 …)를 보여 줍니다.
- **미리 채점**: 촬영 건 여러 개를 골라 미리 채점해 두면 나중에 열 때 베스트컷 결과가 바로 나옵니다(밤새 돌려 두기 좋습니다).

### 베스트컷·C컷 선별
- **컬링 별점**: 표·갤러리·전체 화면 컬링에서 1~5를 누르면 별점을 매기고 남깁니다(0은 별점 지우기). "별점 ★★★ 이상"으로 걸러 볼 수 있고, 라이트룸 **별점 쓰기**는 별점을 매긴 사진을 그 별점으로 씁니다.
- **지난 결과 바로 보기**: 앱을 켜고 이 화면을 열면 지난번 결과가 바로 다시 뜹니다(바뀐 사진만 새로 계산).
- **찾아가기**: Ctrl/⌘+G(또는 F)로 장면 번호나 파일 이름을 넣으면 그 사진으로 갑니다. 같은 이름으로 다시 하면 다음 사진.
- **사진 끌어내기**: 사진을 Finder·라이트룸·메신저로 끌어다 놓을 수 있습니다. Shift를 누르고 끌면 지금 보이는 남기는 컷 전부(파일은 그대로).
- **옵션 ▾** (모두 기본 꺼짐)
  - 단체 사진: 눈뜸을 평균 대신 **가장 낮은 사람** 기준으로 — 한 명이라도 눈을 감으면 점수가 낮아집니다.
  - 브라케팅: 노출을 바꿔 연속으로 찍은 묶음(AEB)을 찾아 "AEB"로 표시하고, 켜면 묶음을 **통째로 남깁니다**(HDR 합성용).
- 처음 미리보기할 때 저장된 점수를 한 번 다시 계산합니다(단체 사진 옵션 때문).

### 시간순 정렬: 이름 규칙
- `{날짜}_{순번:4}`, `김OO_{순번}`처럼 새 이름 규칙을 정할 수 있습니다({순번}·{날짜}·{시각}·{바디}·{원래이름}). 바꾸면 표에 바로 반영됩니다. 기본은 예전과 같은 `00001`.

### 촬영 통계 (폴더 정리 › 살펴보기, 파일 › 촬영 통계…)
- 바디·렌즈별 장 수, 시간대별 촬영량, ISO·셔터속도·조리개·초점거리 분포를 막대 표로 보여 줍니다. 베스트컷 미리보기에서 열면 바디별 남김 수와 C컷 비율까지 보입니다.

### 작업 기록에서 되돌리기 (파일 › 작업 기록… › 되돌리기)
- 지난 C컷·베스트컷 이동, 폴더 정리 이동, 시간순 정렬(이름 바꾸기·합치기)을 원래 자리·이름으로 되돌립니다. 원래 자리에 다른 파일이 있으면 덮어쓰지 않고 건너뜁니다. 복사·삭제·라이트룸은 대상이 아닙니다.

## 사용성 개선

- **남은 공간 확인**: 베스트컷·C컷 복사/이동, 사진 축소, 고객 셀렉, 시간순 정렬 합치기, 카드 가져오기 전에 공간이 모자라면 미리 알려 줍니다.
- **단축키**: Ctrl/⌘+1~6으로 화면 바꾸기, Ctrl/⌘+Enter로 지금 화면 미리보기.
- **보기 메뉴**: 글자 크기(작게·보통·크게·아주 크게)와 테마(시스템·라이트·다크).
- 설정 내보내기에 별점과 촬영 건 목록도 들어갑니다.

## 업데이트 안내

- **v1.3.0 이상을 쓰고 있다면** 앱을 켤 때 이 버전 알림이 뜹니다. **업데이트**를 누르면 받아서 바꾸고 다시 시작합니다(설정·직접 고른 기록은 그대로). 메뉴 **도움말 > 업데이트 확인…**으로 직접 확인할 수도 있습니다.
- **v1.2.0 이하**는 자동 업데이트 기능이 없어 직접 받아 바꿔야 합니다.
- macOS: 앱이 **응용 프로그램 폴더**에 있어야 자동으로 바꿀 수 있습니다. 처음 한 번은 **우클릭 → 열기**로 실행합니다.
- Windows: zip을 **먼저 푼 뒤** `PixThrough.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
