## 한눈에 보기

- **앱 안에서 바로 업데이트** — 새 버전이 나오면 알려 주고, 누르면 받아서 바꾼 뒤 다시 시작합니다.
- **베스트컷·C컷을 한 화면에서** — 미리보기 한 번으로 남길 컷과 걸러낼 컷을 함께 봅니다.
- **장면별 갤러리** — 장면마다 큰 썸네일로 비교하며 고릅니다.
- **왼쪽 메뉴와 정돈된 화면** — 결과가 넓게 보이고, 처음 쓰는 사람도 순서를 따라가기 쉽습니다.

## 새 기능

### 자동 업데이트
- 앱을 켜면 새 버전이 있는지 확인하고, 있으면 변경 내용과 함께 알려 줍니다("이 버전 건너뛰기"도 가능).
- **업데이트**를 누르면 내 컴퓨터용 파일을 받아 손상 여부를 확인한 뒤, 앱을 바꾸고 다시 시작합니다. 바꾸다 실패하면 예전 앱으로 되돌립니다.
- **도움말 > 업데이트 확인…** 으로 언제든 직접 확인할 수 있고, 같은 메뉴에서 시작할 때 확인을 끌 수 있습니다.
- 설정·마지막 폴더·저장된 점수는 그대로 남습니다.

### 베스트컷·C컷 선별 한 화면
- 미리보기 한 번에 사진마다 **베스트컷(초록) / 보통 / C컷(빨강)** 을 함께 보여 줍니다.
- C컷 기준(선명도·눈뜸)을 정하면 C컷으로 판정된 사진은 베스트컷 후보에서 빠집니다. 기준은 처음엔 꺼져 있습니다(0).
- 기준은 숫자로 넣거나, 표·크게 보기 창에서 사진을 골라 **"이 사진을 선명도(눈뜸) 기준으로"** 지정할 수 있습니다. 바꾸면 바로 다시 판정합니다.
- 적용 버튼이 둘로 나뉩니다: **베스트컷 복사(또는 이동)** 와 **C컷 이동**(확인 후 실행). 직접 넣은 컷은 C컷이어도 옮기지 않습니다.
- C컷을 옮기면 남은 사진으로 장면을 다시 묶습니다.

### 장면별 갤러리
- 장면마다 큰 썸네일로 보여 주고, 남기는 컷은 초록 테두리와 ✓, C컷은 빨간 테두리로 표시합니다.
- 클릭으로 고르고, 더블클릭이나 Enter로 크게 봅니다.
- 단축키: Space 넣기/빼기 · P 넣기 · X 빼기 · ←/→ 사진 · ↑/↓ 장면
- 갤러리와 표를 전환할 수 있고, 마지막에 쓴 보기를 기억합니다.

## 화면 개선

- **왼쪽 메뉴**: "사진 파일 정리(시간순 정렬·폴더 정리)"와 "사진 선별(베스트컷·C컷 선별)"로 나누고, 화면마다 제목과 한 줄 설명을 붙였습니다.
- **결과를 넓게**: 위쪽 설정을 나란히 배치하고 접을 수 있게 해서 결과 표·갤러리가 남는 공간을 다 씁니다.
- **결과 표**: 점수 칸 아래 막대, 선명도는 "장면 안 n위"로 표시, 머리글을 눌러 정렬, "남기는 컷만 보기", 표에서도 단축키 사용.
- **처음 화면 안내**: 결과가 없을 때 해야 할 순서를 보여 주고, 끝난 단계는 ✓로 바뀝니다.
- **입력 폴더**: 베스트컷과 C컷이 입력 폴더 칸 하나를 같이 쓰고, 폴더를 끌어다 놓을 수 있습니다.
- **폴더 정리**: 버튼을 "살펴보기 / 정리 / 삭제" 세 칸으로 나누고 버튼마다 설명을 붙였습니다. 삭제 버튼은 빨간 글자입니다.
- 창 크기·위치와 마지막 화면을 기억하고, 확인·취소 같은 기본 대화상자 글자가 한국어로 나옵니다.

## 설치·업데이트 안내

- **v1.2.0 이하에서 올리는 경우 이번 한 번은 직접 받아 바꿔야 합니다.** 다음 버전부터는 앱이 알아서 업데이트합니다.
- **macOS**: `PixThrough-macOS.zip`을 풀어 `PixThrough.app`을 **응용 프로그램 폴더로 옮긴 뒤** 실행하세요(다운로드 폴더에서 바로 실행하면 자동 업데이트가 앱을 바꾸지 못합니다). 처음 한 번은 **우클릭 → 열기**로 실행합니다.
- **Windows**: `PixThrough-Windows.zip`을 **먼저 푼 뒤** `PixThrough` 폴더 안의 `PixThrough.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. Program Files처럼 쓰기 권한이 없는 곳에 두면 자동 업데이트 대신 다운로드 페이지를 열어 줍니다.
